# Spec Delta

## Purpose

Defines how each harness gets only its own tool names for the gauntlet agents.

## ADDED Requirements

### Requirement: Claude Code tool lists
Every agent in `plugins/gauntlet/agents/` with a `tools` line SHALL list only Claude Code tool names and `mcp__plugin_gauntlet_gauntlet__<tool>` names of registered server tools.

#### Scenario: Mixed list rejected
- **WHEN** a `tools` line contains a pi name such as `read`
- **THEN** the Claude Code list check fails and names it.

### Requirement: pi tool lists
The plugin SHALL ship one generated file per agent in `plugins/gauntlet/pi-agents/`, whose `tools` line, where present, lists only pi names: `read`, `bash`, `edit`, `write`, `grep`, `find`, `ls`, `subagent`, and `mcp:gauntlet/<tool>` for registered server tools.

#### Scenario: eta launches on pi
- **WHEN** the generated eta is launched by pi-subagents
- **THEN** the run reports no "unavailable child tools".

#### Scenario: Mixed list rejected on pi
- **WHEN** a pi `tools` line contains a Claude Code name such as `Read`
- **THEN** the pi list check fails and names it.

### Requirement: Read-only roles
eta and zeta SHALL get no shell, edit, write or agent tools on either harness; on pi their tools SHALL be exactly `read`, `grep`, `find`, `ls`.

#### Scenario: zeta on both harnesses
- **WHEN** zeta's Claude Code and pi lists are inspected
- **THEN** neither has `Bash`, `Edit`, `Write`, `Agent`, `bash`, `edit`, `write` or `subagent`.

### Requirement: epsilon's server tools on pi
epsilon's pi file SHALL select every gauntlet server tool as `mcp:gauntlet/<tool>` and set `async: true`.

#### Scenario: All server tools
- **WHEN** epsilon's pi tools are inspected
- **THEN** the `mcp:gauntlet/` entries are exactly the server's registered tools.

### Requirement: One source, checked
The pi files SHALL be generated by `scripts/build_pi_agents.py` from the `pi-<key>` entries of the source agents, and `--check` SHALL fail, naming the file, when a generated file differs from what the source produces.

#### Scenario: Stale copy
- **WHEN** a source agent changes and the generator is not rerun
- **THEN** `scripts/build_pi_agents.py --check` exits non-zero naming the stale file, and the test suite fails.
